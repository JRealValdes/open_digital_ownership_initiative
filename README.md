# Open Digital Ownership Initiative

An open community proposal for **durable ownership of video games** in a
digital-first market—without giving up digital convenience, and without
throwing away physical ownership where it still matters.

> **Buying a game should mean owning a game copy**—with the rights to
> keep, play, preserve, lend, and transfer it—not merely renting
> permission that disappears with a store or an account.

## Why this exists

Digital distribution is convenient. It should not quietly replace
ownership with a non-transferable, account-bound licence that can vanish
when a platform changes strategy or shuts down.

This initiative proposes a practical model where:

- ownership belongs to the **person**, not the account
- **digital** and **offline/physical** modes express the same right
- second-hand sale, lending, and preservation remain possible
- security targets fraud, not ordinary owners

## How to participate

1. Read the [framework](docs/framework.md).
2. Open an [issue](https://github.com/JRealValdes/open_digital_ownership_initiative/issues) to discuss an idea, or a pull request for a concrete edit.
3. For structural changes to the model, use the [RFC process](rfcs/README.md).

Please keep discussion professional, precise, and non-sensational. Critique the design; improve the text.
