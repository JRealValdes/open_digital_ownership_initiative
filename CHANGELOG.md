# Changelog

All notable changes to this proposal are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and version numbers follow the intent described in
[`CONTRIBUTING.md`](CONTRIBUTING.md).

## [1.0.0] — 2026-08-02

### Added

- Initial public draft of the Digital Ownership Framework.
- Explicit non-negotiable ownership rights: ownership, preservation,
  lending, and transfer (including second-hand acquisition).
- Cross-platform portability between competing ecosystems marked out of
  scope; multi-device use within a platform remains in scope.
- Repository structure for open review: framework, glossary, FAQ, and
  RFC process.
- Creative Commons Attribution 4.0 license.
